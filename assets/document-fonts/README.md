# Document fonts

These unmodified fonts are served only to document editors and PDF export. They are not loaded by the home or resource workspace.

- NanumGothic Regular/Bold: https://github.com/google/fonts/tree/main/ofl/nanumgothic
- NanumMyeongjo Regular/Bold: https://github.com/google/fonts/tree/main/ofl/nanummyeongjo
- Liberation Sans/Serif Regular/Bold/Italic/BoldItalic: Liberation Fonts (Debian fonts-liberation distribution), https://github.com/liberationfonts/liberation-fonts

The corresponding OFL and Liberation license files are included here and in the generated site's `document-font-licenses.txt`.

For consistent browser/PDF geometry, Arial and Calibri display with Liberation Sans; Times New Roman with Liberation Serif; Korean sans-serif with NanumGothic; Korean serif with NanumMyeongjo. Font names in the underlying Word document remain unchanged. These are metric-compatible or readable alternatives, not Microsoft font binaries.
