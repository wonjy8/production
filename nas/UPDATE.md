# NAS 업데이트 — 0.1.14

## NAS 0.1.12 기준 교체 ZIP

웹 0.1.13은 NAS 실행 파일 변경이 없으므로 같은 기준입니다. 이번 ZIP은 아래 세 파일만 교체합니다.

- `access.py`: 이름 1~160자·메모 2000자, 행사 날짜/예산 범위, 회계 금액/VAT/지급 상태를 서버에서도 검사합니다. 바꾸지 않은 예전 기록은 유지합니다. 개요 보기 권한이 없으면 행사 상세 정보를 숨깁니다. 일정 권한으로 대표 일정 날짜를 바꿀 때 숨겨진 예산·리스크는 보존하며, 다른 항목을 수정하는 우회 요청은 거절합니다.
- `README.md`, `UPDATE.md`: 최신 운영·적용 안내입니다.

## 적용

1. 기존 `.env`와 `data/` 전체(DB·`account.key` 포함)를 백업합니다.
2. ZIP의 세 파일을 기존 NAS 설치 폴더에 덮어씁니다. `.env`, `data/`, 포트, HTTPS 프록시와 계정 키는 유지합니다.
3. 기존 폴더에서 실행합니다.

```sh
sh update.sh
```

기존 스크립트가 DB 백업 후 Docker 이미지를 재빌드하고 컨테이너를 재생성합니다. 단순 재시작은 부족합니다. Container Manager에서는 기존 프로젝트를 재빌드·재생성하세요. 새 스키마·환경변수·Python 의존성은 없습니다. NAS에 직접 접속해서 적용한 업데이트가 아닙니다.

## 확인

- 기존 계정 로그인과 자료·공유 링크를 확인합니다. 설정의 웹 앱 버전은 `0.1.14`입니다.
- 행사 상세 정보와 일정 날짜를 각각 바꾸고 재접속해 동기화를 확인합니다.
- 회계에서 잘못된 금액이 기존 값을 덮지 않고, 증빙이 보관함 원본으로 유지되는지 확인합니다.
- 개요 수정 권한이 없는 계정의 일정 날짜 변경과 비공개 예산·리스크 보호를 확인합니다.

기준 버전을 모르면 이 증분 ZIP 대신 최신 전체 NAS 업데이트 ZIP을 사용하세요. 기존 설치에서 `install.sh`를 새로 실행하지 않습니다. 코드를 되돌려도 사용자 데이터는 자동으로 되돌아가지 않습니다.
