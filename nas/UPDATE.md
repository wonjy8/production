# NAS 업데이트 — 0.1.12

일정 설정·속성 템플릿과 업무그룹 템플릿의 권한 처리를 보강합니다. 화면의 일정 첨부·행사 그룹·모듈 기능은 웹 배포로 갱신되며, 아래 서버 권한 변경에는 이번 재빌드가 필요합니다.

## NAS 0.1.11 기준 교체 ZIP

- `access.py`: 일정 설정/속성 템플릿은 일정 권한으로 검사합니다. 일정 열람이 금지되면 일정 첨부·설정·속성 틀을 숨깁니다. 업무그룹 템플릿의 원본 탭 권한을 검사하고, 보이지 않는 템플릿은 다른 설정을 저장해도 보존합니다. 실제 행사 그룹의 대표 일정에 한해 제목·행사일·메모의 연결 갱신을 허용합니다.
- `README.md`, `UPDATE.md`: 최신 운영·적용 안내입니다.

기존 설치 폴더에 위 세 파일을 덮어쓰고 다음을 실행합니다.

```sh
sh update.sh
```

기존 스크립트가 DB를 백업한 뒤 Docker 이미지를 재빌드하고 컨테이너를 재생성합니다. `.env`, `data/`, DB, 계정 키, 포트·HTTPS 프록시 설정을 유지하세요. 새 환경변수·DB 스키마·Python 의존성 변경은 없습니다. Container Manager를 사용하면 같은 프로젝트 폴더에서 재빌드·재생성합니다.

## 적용 확인

1. 기존 계정으로 로그인하고 설정에서 웹 앱 버전 `0.1.12`를 확인합니다.
2. 일정에 링크·파일·사진·속성을 추가한 뒤 새로고침해 유지되는지 확인합니다.
3. 일정 설정의 소속 선택/할일 표시와 업무그룹 템플릿을 저장합니다. 권한이 없는 일정·원본 탭은 표시되지 않아야 합니다.
4. 행사 그룹의 대표 일정을 수정하고, 기존 공유 링크의 로그인·열람·다운로드 제한을 확인합니다.

웹 배포는 자동으로 적용되지만 운영 NAS 파일은 이 ZIP으로 직접 교체해야 합니다. 공유 화면은 기존 0.1.11 방식대로 공용 화면 파일만 NAS가 받아 제공합니다. 공유 토큰·계정 정보·자료를 화면 호스트에 전달하지 않습니다.

NAS 버전이 0.1.11이 아니거나 기준이 불명확하면 최신 전체 `production-nas-update.zip`을 사용하세요. 먼저 `.env`와 `data/`를 백업하고 기존 설치 폴더에 코드만 덮어쓴 뒤 `sh update.sh`를 실행합니다. 신규 설치용 `install.sh`는 기존 설치에 실행하지 않습니다. 설치·HTTPS 전달 설정은 [INSTALL.md](INSTALL.md), 계정 운영은 [README.md](README.md)를 참고하세요.
