# 0.1.3 외부 공유

0.1.2 NAS에서 다음 **8개 실행 파일을 함께 적용**합니다.

| 파일 | 변경 |
| --- | --- |
| `sharing.py` | 새 파일. 공유 선택·권한 검사, 만료·중지·파일 제공 |
| `public_gateway.py` | 새 파일. 공개 읽기 화면 경로와 같은 출처 계정 로그인 |
| `share-view.html` | 새 파일. 공통 디자인 언어를 사용하는 읽기 전용 화면 |
| `server.py` | 공유 API와 공개 게이트웨이 등록 |
| `browser_gateway.py` | 인증된 공유 관리 API 및 기능 지원 응답 |
| `completion.py` | 완료 시 해당 프로젝트의 파일 선택을 보존본 ID로 전환 |
| `schema.sql` | `public_shares` 테이블·인덱스 추가. 기존 데이터 유지 |
| `Dockerfile` | 새 서버·화면 파일을 이미지에 포함 |

`.env`, `data/`(파일·DB·계정 키), `compose.yaml`은 유지합니다. 새 환경변수와 의존성은 없습니다. 0.1.2보다 오래된 NAS는 업데이트 ZIP의 실행 소스를 모두 적용하되 설정·데이터를 유지하세요.

## 적용

1. 기존 `data/` 전체를 백업합니다.
2. 앱의 NAS 업데이트 ZIP에서 위 8개 파일을 기존 프로젝트 폴더에 덮어씁니다.
3. 기존 프로젝트 폴더에서 `sh update.sh`를 실행합니다. 스크립트가 SQLite DB를 백업한 뒤 `docker compose up -d --build`로 재빌드·재생성합니다. DSM Container Manager에서는 이미지 재빌드 후 컨테이너를 다시 생성하세요. 단순 재시작으로는 적용되지 않습니다.
4. 역방향 프록시가 같은 NAS HTTPS 호스트의 `/public/` 경로도 이 컨테이너로 전달하는지 확인합니다. 앱에서 연결한 NAS 주소가 받는 사람의 네트워크에서도 열려야 합니다. 공개 로그인은 같은 출처를 검사하므로 원래 Host 헤더도 유지하세요. API 서비스 토큰을 프록시 URL이나 공유 링크에 넣지 않습니다.

## 확인

- 앱에서 공유 설정 패널이 정상적으로 열리는지 확인합니다. API 상태를 점검할 때는 서비스 인증을 포함한 `/api/health` 응답의 `features.publicShares`가 `1`이어야 합니다.
- 앱 상단 **공유**에서 위치와 항목을 선택하고 링크를 만듭니다. 로그아웃한 별도 브라우저에서 선택한 내용만 표시되는지 확인합니다.
- 탭 전체 공유에는 새 항목이 반영되고, 개별 항목 공유에는 다른 항목이 추가되지 않아야 합니다.
- 지정 사용자 링크는 등록된 NAS 계정 이메일만 허용합니다. 받는 사람이 공유 화면에서 로그인하며, 앱 편집 화면 접근 권한은 자동으로 부여되지 않습니다. 별도의 초대 메일은 발송하지 않습니다.
- 다운로드를 끄면 다운로드 버튼과 일반 파일 원본 전달이 차단됩니다. TXT(앞부분 2MB)·DOCX(문서 XML 8MB 이하)는 내용 미리보기, 이미지·영상·음성·PDF는 열람을 제공합니다. 표시되는 내용과 미디어 저장까지 막는 DRM 기능은 아닙니다. 다른 파일 형식은 다운로드를 허용해야 받을 수 있습니다.
- 만료 시각이 지나거나 **공유 중지**를 누르면 기존 링크와 파일 URL 모두 열 수 없어야 합니다.
- 완료하면 같은 링크가 보존본을 표시하고, 다시 진행하면 같은 보존본 ID의 현재 내용을 표시해야 합니다. 다른 프로젝트의 링크는 바뀌지 않아야 합니다.

공유는 읽기 전용이며 선택한 탭·모듈·일정·할 일·파일을 대상으로 합니다. 연결 중인 구형 실시간 모듈/기획 데이터는 독립 사본으로 바꾼 뒤 공유해야 합니다. 공유자는 현재 위치를 열고 공유할 권한이 있어야 하며, 권한 회수·계정 비활성화·위치 삭제는 다음 열람부터 반영됩니다. 공개 응답에는 멤버 연락처·권한 설정·다른 위치·전체 워크스페이스·완료 기록을 포함하지 않습니다.

웹 자동 배포는 운영 NAS를 업데이트하지 않습니다. 이 설치를 마친 뒤 외부 공유를 사용할 수 있습니다. 브라우저 전용 저장 모드는 외부 링크를 만들 수 없습니다.
