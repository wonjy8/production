# 0.0.12 통합 자료 휴지통

0.0.11에서 업데이트할 때는 기존 NAS 프로젝트 폴더의 **resources.py**만 새 파일로 교체합니다. `.env`, `data/`, `compose.yaml`은 유지합니다. DB 스키마와 환경변수 변경은 없습니다.

기존 프로젝트 폴더에서 다음을 실행합니다.

```sh
sh update.sh
```

실행 중인 DB를 백업한 뒤 `docker compose up -d --build`로 Python 소스가 포함된 이미지를 다시 빌드합니다. 단순 재시작만으로는 교체한 소스가 반영되지 않습니다.

적용 확인: 앱을 새로고침하고 모든 자료에서 테스트 파일을 휴지통으로 보낸 뒤, 자료 → 휴지통에서 종류별 보기·복원·영구 삭제를 확인합니다. 다른 프로젝트나 레퍼런스에서 사용하는 원본은 보존합니다. 영구 삭제한 자료의 기록이 다시 자동 등록되지 않도록 최소한의 식별 정보만 남깁니다. 자료 휴지통은 30일 후 다음 자료 조회 때 자동 정리합니다.

0.0.11 썸네일 업데이트를 아직 적용하지 않았다면 `UPDATE-0.0.11.md`에 안내된 `server.py`, `browser_gateway.py`, `requirements.txt`도 함께 교체하여 Pillow를 설치해야 합니다.

앱 버전 롤백은 영구 삭제된 파일을 복구하지 않습니다. 필요한 데이터 복구에는 별도 NAS 백업을 사용합니다.
