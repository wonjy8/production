# 0.1.4 공개 화면 버전 표시 정리

**NAS 0.1.3 기준**으로 교체할 실행 파일은 `share-view.html` 하나입니다. 공개 공유 화면 하단의 앱 버전을 제거하고 공통 디자인 자산을 갱신합니다. 사이드바 개편과 설정의 버전 표시는 웹 배포로 반영됩니다.

1. 기존 NAS 프로젝트 폴더에서 `share-view.html`을 ZIP의 파일로 교체하세요.
2. 기존 `.env`, `data/`, 계정 키, DB, `compose.yaml`은 유지합니다. DB·서버 API·환경변수·의존성 변경은 없습니다.
3. 기존 폴더에서 `sh update.sh`를 실행합니다. SQLite 백업 후 `docker compose up -d --build`로 이미지를 재빌드하고 컨테이너를 재생성합니다. Container Manager를 사용하면 이미지를 다시 빌드하고 프로젝트 컨테이너를 다시 생성하세요. 단순 재시작으로는 이미지 안의 HTML이 바뀌지 않습니다.
4. 기존 공개 공유 링크를 새로 열어 내용과 로그인·다운로드 설정이 유지되고 하단 버전 번호가 사라졌는지 확인하세요. 앱 버전 `v0.1.4`는 앱의 **설정 → 일반**에서 확인합니다.

이 ZIP은 0.1.3의 외부 공유 서버가 이미 설치된 경우에만 사용합니다. NAS 버전이 더 오래되었다면 먼저 해당 버전에서 필요한 서버 업데이트를 적용해야 합니다. 웹 자동 배포는 운영 NAS 파일을 교체하지 않습니다.
