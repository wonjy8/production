# NAS 0.1.10 교체 안내

이 증분 ZIP의 기준은 NAS **0.1.9**입니다. 현재 NAS 버전이 다르면 먼저 해당 기준까지의 업데이트를 적용하세요. 앱 웹 UI는 Pages에서 별도로 자동 배포됩니다.

포함 파일:
- `share-view.html`: 공통 버튼/모듈 디자인 언어 및 공개 공유 화면 버전 0.1.10.
- `UPDATE-0.1.10.md`: 이 안내.

기존 NAS 설치 폴더에서 `share-view.html`을 덮어쓰고 안내 파일을 추가하세요. `.env`, `data/`, DB, 계정 키 및 기존 설정은 교체하거나 삭제하지 않습니다. 서버 API·DB 스키마·의존성 변경은 없습니다.

설치 폴더에서 실행:

```sh
sh update.sh
```

기존 스크립트는 DB 백업 후 Docker 이미지를 재빌드하고 컨테이너를 재생성합니다. Container Manager를 사용하면 같은 프로젝트를 기존 데이터 마운트와 환경변수를 유지한 채 재빌드·재생성하세요. 단순 재시작으로는 이미지 안의 HTML이 바뀌지 않습니다.

확인: 컨테이너 정상 실행, 기존 계정 로그인과 자료 다운로드, 공개 공유 링크 열기를 확인하세요. 앱 설정에서 v0.1.10을 확인하고, 기존 공유 링크의 원본 다운로드도 확인하세요.
