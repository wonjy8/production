# 0.1.7 공통 UI 디자인 자산 갱신

**NAS 0.1.6 기준**으로 교체할 실행 파일은 `share-view.html` 하나입니다. 공통 제목/사이드바 CSS를 최신 빌드와 맞춥니다. 프로덕션 명칭, 고정 좌측 사이드바, 공통 제목 편집, 문서 편집기 비활성화는 웹 자동 배포로 반영됩니다.

1. NAS 프로젝트 폴더의 `share-view.html`을 ZIP 안의 파일로 교체합니다. `UPDATE-0.1.7.md`는 안내서입니다.
2. 기존 `.env`, `data/`, DB, 계정 키, `compose.yaml`을 그대로 유지합니다. 서버 API·DB 스키마·환경변수·의존성 변경은 없습니다.
3. 기존 폴더에서 `sh update.sh`를 실행하여 이미지를 다시 빌드하고 컨테이너를 재생성합니다. Container Manager 사용 시에도 이미지 재빌드와 프로젝트 컨테이너 재생성이 필요합니다. 단순 재시작으로는 이미지 안 HTML이 갱신되지 않습니다.
4. 기존 공유 링크에서 내용·로그인·다운로드가 유지되는지 확인합니다. 앱 설정 → 일반에서 v0.1.7, ‘프로덕션 / 홈’ 경로, 고정된 좌측 사이드바와 제목 편집을 확인합니다. 문서 편집기는 준비 중이며 기존 파일 다운로드는 가능합니다.

운영 NAS 설치 버전은 확인하지 않았습니다. 이 ZIP은 NAS 0.1.6 기준 교체분입니다. 더 오래된 버전은 필요한 서버 업데이트를 먼저 적용하세요. 웹 자동 배포는 운영 NAS 파일을 직접 교체하지 않으며 ZIP에는 사용자 데이터·설정·DB·계정 키가 없습니다.
