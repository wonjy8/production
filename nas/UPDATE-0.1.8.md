# 0.1.8 열 모듈 업데이트

**NAS 0.1.7 기준** 교체 파일은 `sharing.py`, `share-view.html`입니다. `UPDATE-0.1.8.md`는 안내서입니다.

- `sharing.py`: 탭 전체를 외부 공유할 때 내용 없는 열 컨테이너는 제외하고, 열 안의 실제 모듈은 기존 권한·다운로드 정책으로 공유합니다.
- `share-view.html`: 공통 디자인 자산과 표시 버전을 갱신합니다.
- 열 추가·배치·합치기는 웹 자동 배포로 반영됩니다. DB 스키마·환경변수·의존성 변경은 없습니다.

1. 기존 NAS 프로젝트 폴더에서 위 두 파일을 ZIP 안의 같은 이름 파일로 교체하세요.
2. `.env`, `data/`, DB, 계정 키, `compose.yaml`은 유지하세요. ZIP에는 이 파일들이 없습니다.
3. 같은 폴더에서 `sh update.sh`로 **이미지 재빌드와 컨테이너 재생성**을 실행하세요. Container Manager에서도 재빌드·재생성이 필요하며, 단순 재시작으로는 이미지 안 파일이 바뀌지 않습니다.
4. 앱 설정에서 v0.1.8을 확인하고, 테스트 프로젝트에서 2·3·4단 열 추가, 중첩 포함 최대 4칸 제한, 새로고침 후 배치 유지, 구분선 X로 오른쪽 모듈이 왼쪽 아래에 붙는지 확인하세요. 기존 공유 링크의 내용·로그인·다운로드와 열이 있는 탭 전체 공유도 확인하세요.

운영 NAS의 현재 설치 버전은 확인하지 않았습니다. 이 ZIP은 NAS 0.1.7 기준이며, 이전 버전이면 해당 버전까지 필요한 업데이트를 먼저 적용하세요. 웹 자동 배포가 운영 NAS 파일을 직접 교체하지는 않습니다.
