# 0.1.5 공통 디자인 자산 갱신

**NAS 0.1.4 기준** 교체 파일은 `share-view.html` 하나입니다. 공통 디자인 CSS를 사용하는 공개 열람 HTML을 최신 빌드와 일치시킵니다. 사이드바와 앱 안의 문서 편집기 변경은 웹 자동 배포로 적용됩니다. NAS API·DB·환경변수·의존성 변경은 없습니다.

1. NAS 프로젝트 폴더의 `share-view.html`을 ZIP의 파일로 교체합니다. `UPDATE-0.1.5.md`는 안내 파일입니다.
2. 기존 `.env`, `data/`, 계정 키, DB, `compose.yaml`은 그대로 둡니다.
3. 같은 폴더에서 `sh update.sh`를 실행합니다. 기존 SQLite 백업 후 이미지를 다시 빌드하고 컨테이너를 재생성합니다. Container Manager 사용 시에도 이미지 빌드와 프로젝트 컨테이너 재생성이 필요하며 단순 재시작만으로는 HTML이 교체되지 않습니다.
4. 기존 공개 공유 링크에서 내용·로그인·다운로드 동작이 유지되는지 확인합니다. 앱에서는 설정 → 일반의 `v0.1.5`, 아이콘으로 사이드바 열기/닫기, 오른쪽 화면의 문서 편집기를 확인합니다.

운영 NAS의 설치 버전은 확인하지 않았습니다. 이 ZIP은 NAS 0.1.4가 설치된 경우의 교체분입니다. 더 오래된 버전은 해당 서버 업데이트를 먼저 적용하세요. ZIP에는 사용자 설정·데이터·DB·키가 없으며 웹 자동 배포가 운영 NAS 파일을 교체하지는 않습니다.
