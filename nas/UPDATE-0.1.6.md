# 0.1.6 공통 UI 디자인 자산 갱신

**NAS 0.1.5 기준** 교체 실행 파일은 `share-view.html` 하나입니다. 상단 제목과 공통 패널의 디자인 CSS를 최신 빌드와 일치시킵니다. 앱의 제목 배치·문서 툴바·속성 패널·눈금자 변경은 웹 자동 배포로 적용됩니다.

1. NAS 프로젝트 폴더의 `share-view.html`을 ZIP 파일로 교체합니다. `UPDATE-0.1.6.md`는 적용 안내입니다.
2. `.env`, `data/`, DB, 계정 키, `compose.yaml`은 그대로 유지합니다. 서버 API·DB 스키마·환경변수·의존성 변경은 없습니다.
3. 기존 폴더에서 `sh update.sh`를 실행하여 이미지를 다시 빌드하고 컨테이너를 재생성합니다. Container Manager 사용 시 이미지 재빌드와 프로젝트 컨테이너 재생성이 필요합니다. 단순 재시작으로는 이미지의 HTML이 바뀌지 않습니다.
4. 기존 공개 공유 링크의 내용·로그인·다운로드 동작이 유지되는지 확인합니다. 앱 설정 → 일반에서 v0.1.6, 상단 제목 아래 작은 경로, 앱 안의 문서 제목 변경과 새 속성 패널을 확인합니다.

운영 NAS 설치 버전은 확인하지 않았습니다. 이 ZIP은 NAS 0.1.5 기준 교체분입니다. 이전 버전이라면 필요한 서버 업데이트를 먼저 적용하세요. ZIP에는 사용자 데이터·설정·DB·계정 키가 없으며, 웹 자동 배포는 운영 NAS의 파일을 직접 교체하지 않습니다.
