# 0.1.9 프로젝트 색상·일정 UI 업데이트

**NAS 0.1.8 기준** 교체 파일은 `share-view.html` 하나입니다. `UPDATE-0.1.9.md`는 안내서입니다. 공통 디자인 자산과 버전 표시를 갱신합니다. 아이콘·색상·반복 기능은 웹 자동 배포에 포함됩니다.

1. 기존 NAS 프로젝트 폴더의 `share-view.html`을 ZIP 안의 파일로 교체하세요.
2. `.env`, `data/`, DB, 계정 키, `compose.yaml` 등 기존 설정을 유지하세요. ZIP에는 사용자 데이터나 설정이 없습니다.
3. 같은 폴더에서 `sh update.sh`로 **이미지 재빌드와 컨테이너 재생성**을 실행하세요. Container Manager에서도 재빌드·재생성이 필요하며 단순 재시작만으로는 이미지 안 HTML이 바뀌지 않습니다.
4. 앱 설정의 v0.1.9, 제목 옆 아이콘/색상, 한글 이모지 검색, 반복 추가·범위 선택, 종일/시간 일정과 할일의 색상, 캘린더 높이를 확인하세요. 기존 공개 공유 링크의 로그인·내용·다운로드도 확인하세요.

운영 NAS의 설치 버전은 확인하지 않았습니다. 이 ZIP은 NAS 0.1.8 기준이며, 이전 버전이면 필요한 업데이트를 먼저 적용하세요. 웹 배포가 운영 NAS 파일을 직접 교체하지는 않습니다. NAS API·DB 스키마·환경변수·의존성 변경은 없습니다.
