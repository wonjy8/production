- NAS unittest 47개 통과. 서버 API·DB·환경변수·의존성 변경 없음.
- `test-sidebar-rail-browser.py` 통과: 앱 밖 48px 레일, 18px 아이콘, 설정 하단/구분선, 앞 문서의 불투명 바탕, 선택 채움, 별도 토글 버튼 제거, 같은 아이콘 열기/닫기, 다른 아이콘의 사이드바 열기, 닫힌 상태의 포인터/키보드 너비 조절 차단과 열린 상태의 너비 조절을 검사했다.

- `test-original-catalog-browser.py`의 browser-local/NAS 두 모드 통과: 원본 등록·공유 ID·숨긴 사용처·삭제 보호·사용처/사본 UI·원본 편집 동의·독립 사본·연결 해제/복원 유지. 편집기 진입은 앱 내부 프레임으로 검증하도록 갱신했다.
- `test-sharing-browser.py`로 공개 공유 열람·권한·다운로드·완료/재개·중지와 모바일 회귀를 확인했다. 외부 레일의 body 여백은 레일이 있는 앱에만 적용하여 공개 열람 화면에 전파되지 않는다.
- 데스크톱 자료/설정/문서 및 모바일 문서 화면을 캡처해 시각 확인했다. `git diff --check` 통과.

추가 실행한 기존 `test-admin-home-ui.mjs`는 과거 `admin-home-heading` DOM을 전제로 실패했다. 해당 테스트와 `production/AdminHome.tsx`의 SHA256은 v0.1.4와 각각 동일하며 이번 변경 대상이 아니다. 이 검사는 통과로 집계하지 않았다.

전체 기획 완료를 뜻하지 않는다. 제작 템플릿 확장과 새 권한 승인 흐름 등은 PRODUCT-AUDIT-0.1.4.md의 미완료 상태를 유지한다.

운영 NAS에는 접속하거나 파일을 교체하지 않았다. NAS 0.1.4 기준 `share-view.html`과 적용 안내만 포함한 `production-nas-update-0.1.5.zip`을 채팅으로 제공한다. 기존 `.env`/`data`/DB/계정 키를 보존하고 `sh update.sh`로 이미지를 다시 빌드·재생성해야 공개 HTML에 공통 CSS 갱신이 반영된다. 앱의 변경은 Pages 자동 배포로 적용된다.
