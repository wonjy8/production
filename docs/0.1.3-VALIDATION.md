# 0.1.3 외부 공유 검증

- `npm run build`, `npm run validate`, `npm run build:pages` 통과. 앱·Pages `version.json`·NAS 공개 화면 버전은 `0.1.3`이다.
- JavaScript 검사 18개 통과: production, auth-gateway, grade-calculator, figma-connection, pages-route, document-library, planning, resource-schema, completion-summary, completion-policy, sharing, module-placement, module-transfer, task-status, icons, module-tabs, photo-editor, unified-projects.
- `.venv/bin/python -W ignore -m unittest discover -s nas -p 'test_*.py' -q`: 47개 통과. 공유 검사 7개는 탭 전체/개별 선택, 숨겨야 하는 위치·메타데이터 제외, 원본 교체 실시간 반영, 파일 접근·다운로드 제한, TXT/DOCX 미리보기, PDF 인라인 응답, 지정 사용자·세션 위조·로그인 쿠키·CSRF, 만료·중지·버전 충돌, 발급자 권한·멤버십 회수, 다른 프로젝트 링크를 유지하는 완료 전환 및 같은 링크 재개를 다룬다.
- `CHROMIUM_PATH=/usr/bin/chromium NAS_PYTHON=$PWD/.venv/bin/python .venv/bin/python scripts/test-sharing-browser.py`: 로컬 저장의 NAS 안내와 격리된 HTTPS NAS의 실제 공유 화면을 검증했다. 링크 생성/설정 변경, 익명 선택 항목 열람, TXT·PDF 미리보기, 다운로드 허용 전환, 지정 계정 로그인, 탭 전체에만 새 항목 반영, 완료·재개 시 같은 URL 유지, 공유 중지, 모바일 가로 폭을 확인했다. PDF는 Chromium의 실제 PDF 뷰어 플러그인 표시를 검사하고 화면도 확인했다.
- 같은 환경에서 `scripts/test-completion-browser.py`와 `scripts/test-original-catalog-browser.py`: 브라우저 저장·NAS 모두 통과. 완료 보존·잠금·재개와 기존 원본 등록·사용처·삭제 보호·사본·문서 선택·휴지통 복원 회귀를 확인했다.
- 공통 디자인 CSS·공개 화면 스크립트 구문, `git diff --check` 통과. 공개 내용은 HTML로 삽입하지 않고 텍스트 노드로 표시한다.
- NAS 업데이트 ZIP의 실행 파일 8개와 UPDATE-0.1.3.md가 테스트한 소스와 일치하고 `.env`·DB·계정 키를 포함하지 않음을 확인했다. 공개 열람 화면은 `ui/share-view.html`, `ui/share-view.js`와 `ui/design-system/`에서 빌드한다.

운영 NAS에 접속해 설치한 것은 아니다. [업데이트 안내](../nas/UPDATE-0.1.3.md)의 파일 교체·이미지 재빌드와 같은 NAS HTTPS 호스트의 `/public/` 프록시 전달이 필요하다. 지정 사용자는 등록된 NAS 계정을 사용한다. 브라우저 전용 저장은 외부 공유를 만들 수 없다. 다운로드 제한은 DRM이 아니며, 렌더링된 내용·미디어 저장까지 막지 않는다. TXT 미리보기는 앞부분 2MB, DOCX 미리보기는 문서 XML 8MB 이하이다.

기존 `test-resource-database-browser.py`의 예전 전용 속성 가정과 현재 일반 속성의 불일치는 [0.1.1 검증 기록](0.1.1-VALIDATION.md)에 남아 있다. 이번에는 이 검사를 재실행하거나 통과했다고 처리하지 않았다.
