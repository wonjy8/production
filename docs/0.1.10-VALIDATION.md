제거된 모듈은 보기에서 메모·파일로 전환하고 편집 시 저장한다. 단순 열람으로 잠긴 완료 자료를 다시 쓰지 않는다. 기존 필드 전체는 문자열 스냅샷으로 보존하며, 파일 원본 ID는 파일 모듈에서 유지한다. 과거 모든 기획 항목의 완료를 이번 검사 결과로 주장하지 않는다. 기존 별도 타임테이블 편집기의 반복 적용 범위를 새로 확장하지 않는다.

운영 NAS의 파일을 직접 교체하지 않았다. NAS 0.1.9 기준 `share-view.html`, `UPDATE-0.1.10.md`만 담은 `/workspace/artifacts/production-nas-update-0.1.10.zip`을 제공한다. ZIP 검사·파일 대조를 통과했으며 설정·data/DB/계정 키는 포함하지 않는다. `sh update.sh`로 이미지를 재빌드하고 컨테이너를 재생성한다. 웹 UI는 main 푸시에 따른 Pages 자동 배포 대상이다.
