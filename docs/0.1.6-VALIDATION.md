- `test-sidebar-rail-browser.py`: 일반 DOM 설정 제목과 Shadow DOM 홈/프로젝트 제목이 상단바에 표시되고, 작은 경로가 아래에 있으며 본문 중복 제목과 빈 제목 행이 사라지는지 검사했다. 프로젝트 아이콘 변경과 탭은 같은 행에 보존했다.

- `test-document-rulers-browser.py`의 browser-local/NAS 두 모드에서 눈금자/종이 정렬, 100%/50%/화면 맞춤 배율, A5 용지 크기, 여러 페이지의 세로 눈금 초기화, 스크롤 고정, 모바일 범위, 실제 selectable-text PDF와 DOCX에서 눈금자 문구가 제외되는 것을 확인했다.
- `test-original-catalog-browser.py`의 browser-local/NAS 두 모드에서 원본 등록·사용처·삭제 보호·사본·문서 원본 편집 동의·독립 사본·연결 해제/복원 보존을 확인했다.
- `test-sharing-browser.py`: 공개 열람·선택 범위·로그인/다운로드 권한·완료/재개·중지·모바일 회귀 확인. 공개 공유 화면에는 앱 제목 승격을 적용하지 않는다.
- 데스크톱 프로젝트/설정/문서와 모바일 문서 화면을 캡처하여 시각 점검했다. `git diff --check` 통과.

기존 `test-admin-home-ui.mjs`의 과거 DOM 전제 문제는 0.1.5-VALIDATION.md에 기록되어 있다. 이번 릴리스에서 해당 테스트를 수정하거나 통과했다고 집계하지 않았다. 전체 기획 완료를 뜻하지 않으며 제작 템플릿/새 권한 승인 흐름은 PRODUCT-AUDIT-0.1.4.md의 미완료 상태를 유지한다.

운영 NAS에 접속해 파일을 교체한 것은 아니다. NAS 0.1.5 기준 `share-view.html`과 안내서만 포함한 `production-nas-update-0.1.6.zip`을 채팅에 제공한다. 기존 `.env`, `data/`, DB, 계정 키를 보존하고 `sh update.sh`로 이미지를 재빌드·재생성한다. 앱 UI는 Pages 자동 배포로 적용된다.
