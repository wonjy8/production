# 0.1.7 프로덕션 탐색·고정 사이드바·공통 제목 편집 검증

- VERSION 0.1.7. `npm run build`, `npm run validate`, `npm run build:pages` 통과.
- JavaScript 검사 20개 통과: production, auth-gateway, grade-calculator, figma-connection, pages-route, document-library, planning, resource-schema, completion-summary, completion-policy, sharing, module-placement, module-transfer, task-status, icons, module-tabs, photo-editor, unified-projects, history, title-editor. title-editor 검사를 Pages CI에도 추가했다.
- NAS unittest 47개 통과. 서버 API·스키마·환경변수·의존성 변경 없음.
- `test-sidebar-rail-browser.py`: 프로덕션/홈 및 프로젝트 경로, 별도 홈 항목, 자료 영역, 비활성 문서 아이콘을 확인했다. 좌측 패널의 fixed 위치·y=0·뷰포트 높이·0px 모서리·그림자 없음과 스크롤 후 유지 상태를 좌표로 검사했다.
- 같은 검사에서 사이드바를 닫는 애니메이션의 중간 프레임마다 사이드바 오른쪽 경계·상단바·본문 왼쪽 좌표가 일치하는지 확인했다. 닫힌 너비 조절 차단과 열린 키보드 조절을 유지했다. 초기 CSS 적용에서 본문만 움직이지 않게 준비 프레임 이후 모션을 활성화했다.
- 제목 편집: 프로젝트 Enter 저장·Esc 취소, 업무 그룹 입력 후 홈 이동 시 저장 대기, 자료 제목 저장, 멤버 이름의 기존 자동 저장 경로를 실제 API 데이터와 대조했다. 완료 프로젝트는 제목 편집이 잠긴다. 실패 응답을 주입한 프로젝트 제목 저장 후 취소 시 기존 이름이 남는 것도 확인했다.
- 공통 title-editor 단위 검사는 공백 거절·중복 제출 합치기·저장 중 blur 재진입·실패 재시도·권한 변경·대상 변경·blur 저장·취소를 확인했다. 도메인별 권한 스코프를 상단 편집 입력에도 연결했다.
- 우측 모듈 패널은 fixed 플로팅 위치와 18px Squircle를 유지한다. 모바일 좌측 패널은 별도 고정 레이어로 두어 제목/본문의 transform을 따라 밀려나지 않게 했고, 제목/본문의 이동량과 닫힌 뒤 화면 가로 범위를 검사했다.
- 문서 편집기: 셸/React가 공유하는 features.js에서 비활성화한다. 레일·파일/텍스트 변환 버튼·생성 헬퍼·복원 경로·직접 문서 URL을 막는다. 새 문서/프레임을 만들지 않고 엔진 자산을 요청하지 않으며 기존 원본 바이트와 다운로드가 유지되는 것을 검사했다.
- `test-original-catalog-browser.py`의 browser-local/NAS 두 모드: 즉시 원본 등록·공유 ID·숨긴 사용처·삭제 보호·사본·연결 해제/복원 유지, 편집기 중단 중 원본 다운로드를 확인했다. 편집기 기능을 켰을 때의 원본/사본 편집 동의 검사는 코드에 유지하되 이번 비활성 상태에서는 실행·통과로 집계하지 않았다.
- `test-sharing-browser.py`: NAS 필요 안내, 공유 생성/수정, 익명/지정 사용자 열람, 선택 범위·다운로드 권한, 완료/재개 같은 링크, 중지와 모바일 범위 통과.
- 데스크톱 프로젝트/설정/비활성 안내 및 모바일을 캡처하여 시각 점검했다. `git diff --check` 통과.

이 검증은 전체 기획 완료를 뜻하지 않는다. 제작 템플릿/새 권한 승인 흐름 등은 PRODUCT-AUDIT-0.1.4.md의 미완료 상태를 유지한다. 기존 test-admin-home-ui.mjs의 과거 DOM 전제 문제는 이전 검증 기록에 남아 있으며 이번 통과 개수에 포함하지 않았다. 문서 편집/눈금자/내보내기는 기능 중단에 따라 이번 릴리스에서 실행 가능한 기능으로 보고하지 않는다.

운영 NAS에 접속해 파일을 교체한 것은 아니다. NAS 0.1.6 기준 share-view.html과 안내서만 포함한 production-nas-update-0.1.7.zip을 채팅에 제공한다. 기존 .env/data/DB/계정 키는 보존하고 sh update.sh로 이미지 재빌드·컨테이너 재생성 후 공개 공유 동작을 확인한다. 앱 UI는 Pages 자동 배포로 적용된다.
