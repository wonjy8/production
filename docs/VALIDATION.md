## 적용과 한계

- 운영 NAS 직접 접속 검증은 아니다. NAS 0.1.12(웹 0.1.13 포함) 기준 교체 ZIP의 `access.py`, `README.md`, `UPDATE.md`를 사용자가 덮어쓰고 재빌드한다. DB·파일·환경변수·계정 키는 포함하지 않는다. 스키마/의존성 변경은 없다.
- 일정을 날짜 이동하면 명시한 개인 종료일도 같은 일수만큼 이동한다. 개인이 별도로 정한 시각은 유지하며 충돌을 다시 검사한다.
- 충돌은 열람 가능한 데이터와 편집 기준 날짜를 검사한다. 날짜·시간 미정 할일과 무기한 미래 반복 전체의 충돌을 보장하지 않는다. 기본 휴식 경고는 60분이며 저장을 막지 않는다.
- 새 행사 기간을 지정하면 대표 일정을 생성한다. 이미 연결된 기간을 미정으로 바꾸려면 대표 일정을 먼저 삭제한다. 기존 상시 기록이나 과거에 이미 합쳐진 인원을 임의 복원/변환하지 않는다.
- 예산은 회계 모듈별로 관리하며 새 모듈은 해당 프로젝트의 예산 상한을 기본값으로 사용한다. 계약·지급 예정·실지출을 중복 합산하지 않고 항목별 최대 약정액을 반영한다. 지급 완료가 입력 실지출보다 크면 완료 합계를 반영한다.
- 물리 iOS/Pencil 검사, 외부 회계 연동, 세금 신고, 교대 자동 편성은 범위에 포함하지 않는다. TypeScript 검사는 공통 모듈 범위의 strict=false이며 앱 전체 엄격 타입 검사가 아니다. 나머지 기획 범위는 PRODUCT-AUDIT.md에 유지한다.
