- `npm run build`, `npm run validate`, `npm run build:pages`, `git diff --check` 통과. 설정 표시 버전은 0.1.8이다.
- JavaScript 검사 26개 통과: production, auth-gateway, grade-calculator, figma-connection, pages-route, document-library, planning, resource-schema, completion-summary, completion-policy, sharing, module-placement, module-transfer, task-status, icons, module-tabs, photo-editor, unified-projects, history, title-editor, module-hub, imported-modules, module-undo, module-resize, module-height, columns.
- `test-columns.mjs`: 2단 안에 3단을 둔 4칸 구조, 초과 분할 차단, 자기 자손으로 이동하는 순환 차단, 280/700/1200px 배치, 빈 슬롯 드롭, 오른쪽 내용의 순서 보존 병합, 마지막 경계 해제, 파일 ID 보존, 기존 배치의 결정적 변환, 자식/하위 구조 탭 이동 및 기존 목적지 배치 보존을 검사한다. Pages CI에 추가했다.
- `test-columns-browser.py`: browser-local/NAS 두 모드에서 중첩 4칸, 빈 열에 추가, 실제 포인터로 중첩 열에 이동, 저장 완료 후 새로고침 복원, 평소 투명한 선/X의 접근 표시, 포인터 너비 조절 저장, 오른쪽 B/D가 왼쪽 A 아래에 순서대로 붙는지, 모든 경계 삭제 후 모듈 유지, 2단 추가 후 양쪽에 2단을 중첩하는 실제 메뉴 흐름, 최대 칸 수에 따른 메뉴 비활성화, 기존 6/6 배치의 최초 편집 전환과 ID 유지, 완료 읽기 전용 영역에서 컨트롤 숨김을 확인한다. 저장 검증은 자동 저장 완료를 명시적으로 기다린 후 수행한다.
- NAS unittest 48개 통과. 새 검사는 탭 전체 외부 공유 시 열 컨테이너가 빈 카드로 노출되지 않고, 안의 텍스트/파일은 기존 공개 범위를 유지하는지 확인한다.
- `test-sidebar-rail-browser.py` 통과: 기존 고정 좌측 사이드바와 상단바/본문 동기 이동, 제목 저장/취소/완료 잠금, 문서 편집기 중단, 원본 보존과 모바일 배치 유지. 버전 기대값만 0.1.8로 갱신했다.
- `test-sharing-browser.py` 통과: NAS 연결 안내, 공유 생성/수정, 익명/지정 사용자, 선택 범위·파일 미리보기·다운로드, 완료/재개·중지, 모바일 범위 유지.
- 열 컨테이너는 별도 중첩 파일 트리가 아니라 기존 모듈 컬렉션에 슬롯 소속 관계를 더한다. 기존 파일 참조·권한·검색·완료 보존 경로를 유지한다. 기존 배치는 읽는 것만으로 저장하지 않으며 실제 편집 시 명시적 열 구조를 함께 저장한다. 재사용/가져오기에서는 열 껍데기 대신 실제 콘텐츠를 선택하며, 원본의 슬롯 소속 관계는 가져오지 않는다.
- UI 원칙은 `ui/design-system/columns.css`, README, INVENTORY와 PRODUCT-DECISIONS에 기록했다. 새로운 화면/탭 진입 모션은 없고, 문서 편집기는 계속 비활성이다. 공개 공유 화면은 기존 콘텐츠 목록 표시 방식을 유지한다.

전체 기획이 완료되었다는 의미는 아니다. 이전 PRODUCT-AUDIT의 미완료 항목과 과거 DOM 전제를 가진 `test-admin-home-ui.mjs`는 이번 통과 검사에 포함하지 않는다. 자유로운 옆 배치를 전제로 한 이전 브라우저 배치 검사는 새 `test-columns-browser.py`로 현재 동작을 검증한다.

운영 NAS 파일은 직접 교체하지 않았다. NAS 0.1.7 기준 교체분 `sharing.py`, `share-view.html`, 안내서만 포함한 `production-nas-update-0.1.8.zip`을 채팅으로 제공한다. `.env`/DB/data/계정 키는 보존하고 `sh update.sh`로 이미지 재빌드·컨테이너 재생성한다. DB 스키마·환경변수·의존성 변경은 없다.
