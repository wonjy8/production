- 모바일 390px에서 제목 아이콘 선택기 경계가 화면 안에 있는지, 대한민국 국기 검색과 이모지 표시를 확인했다. 데스크톱 일정과 모바일 선택기를 캡처해 시각 확인했다.
- `test-recurrence.mjs`: 시간대·DST와 무관한 날짜 계산, 월말/윤년 보정, 다일 일정, 종료일·간격 검증, 이번만/이후/전체 수정·삭제, 반복 중단, 이동한 예외의 검색 범위 이동, 전체 날짜 이동 시 예외 날짜 유지, 이후 주기 변경, 완료 이력을 보존한 전체 이름 변경, 긴 반복 간격, 완료 후 다음 회차, 홈/일정 목록의 같은 원본 수정과 UI 전용 정보 비저장을 확인한다. 목록은 끝없는 회차를 복제하지 않고 완료 이력과 가장 이른 미완료 회차를 표시한다.
- `test-project-identity.mjs`: 현재 팩의 1,914개 전부 한국어 이름/검색어 연결, 한글/영문 검색, 잘못된 CSS 색상 거절, 같은 색의 옅은 배경 생성을 확인한다. Unicode CLDR 기본/파생 한국어 주석의 해당 이모지만 포함하고 라이선스를 저장했다. 색상은 SVG에 적용하며 이모지·업로드 이미지는 원래 그림을 유지한다.
- `test-sidebar-rail-browser.py`: v0.1.9 표시, 기존 고정 좌측 사이드바·제목/본문 이동 동기화·공통 제목 저장/취소·완료 잠금·중단된 문서 편집기·원본 유지·모바일 배치 통과.
- `test-columns-browser.py`: 기존 중첩 4칸 제한, 열 추가·드래그·너비 조절·합치기·저장, 기존 배치 전환과 완료 영역 컨트롤 숨김을 browser-local/NAS 양쪽에서 확인했다.

반복 규칙 자체를 바꾸는 경우에는 이번부터 이후/전체를 선택하도록 안내한다. 이번만은 특정 회차의 내용·날짜 변경/삭제에 사용한다. 기존 공개 공유 서버의 콘텐츠 투영은 유지하며, 외부 공유 화면을 반복 회차 달력으로 바꾸는 작업은 포함하지 않는다. 타임테이블의 별도 편집기를 새 반복 편집기로 교체하는 작업도 이번 일정 탭 범위에 포함하지 않는다. 기존 전체 기획 감사의 미완료 항목과 과거 DOM 전제의 admin-home-ui 검사를 이번 완료/통과로 집계하지 않는다.

운영 NAS에 접속해 파일을 바꾼 것은 아니다. NAS 0.1.8 기준 `share-view.html`, `UPDATE-0.1.9.md`만 포함한 `production-nas-update-0.1.9.zip`을 채팅에 제공한다. 기존 설정·DB/data/키를 보존하고 `sh update.sh`로 이미지 재빌드·컨테이너 재생성한다. 웹 UI는 Pages 자동 배포 대상이다.
