## 기존 검사 제한

`scripts/test-resource-database-browser.py`는 로컬 썸네일·캐시·원본 교체 검사까지 통과한 뒤, 새 문서의 기본 속성에서 '장소' 입력을 기다리다가 실패했다. 현재 기본 속성은 분류·날짜·설명이고 해당 테스트는 이전 말씀 노트 전용 장소·설교자·본문 구절 필드를 가정한다. 변경 전 HEAD의 production/resource-schema.js도 같은 일반 기본 속성이므로 기존 테스트와 현재 제품의 불일치다. 이 검사를 통과했다고 보고하지 않으며 기본 속성을 과거 구성으로 되돌리거나 검사를 비활성화하지 않았다. 현재 원본 관리 흐름은 별도 통합 검사로 검증했다.

운영 NAS의 설치/데이터에 접근해 검증한 것은 아니다. 프런트엔드 배포와 별개로 NAS 업데이트가 필요하며 nas/UPDATE-0.1.1.md에 파일·재빌드·확인 절차를 기록했다. 완료 보존본·외부 공유·새 권한 승인 체계·템플릿은 후속 단계이다.
