# 공통 UI

`icons.js`: 24px 그리드, 1.75px 선, 둥근 끝과 모서리를 사용하는 앱 공통 SVG 아이콘팩입니다. 메인 문서와 React 제작 화면에서 같은 자산을 사용합니다.

`controls.css`: 버튼·입력·선택 컨트롤을 높이 40px, 모서리 10px, 테두리 1px로 통일합니다. 내용 카드와 일정 항목은 별도의 콘텐츠 요소입니다. 작업 버튼은 아이콘을 우선 표시하고 접근성 이름과 툴팁을 유지합니다.

`layout.css`: 검색 가능한 다중 프로젝트 목록과 플로팅 사이드바를 구성합니다. 모바일에서는 홈·자료·데이터베이스·설정 하단 탐색을 사용합니다.

운영자료는 별도 앱 메뉴 없이 프로젝트의 제작 화면 안에서 표시합니다. 기존 문서 편집 DOM은 슬롯으로 넣어 데이터와 편집 기능을 그대로 유지합니다.

설정 → 일반에서 검정·파랑·빨강·보라·초록 강조 색을 선택합니다. 브라우저에 저장하고 메인 문서와 Shadow DOM 화면에서 같은 색 변수를 상속합니다.

공유·검색·모듈 허브는 상단바 아래의 같은 위치와 높이를 사용하는 우측 패널입니다. 패널 간 이동 시 기존 패널을 닫으며 메인 화면의 너비를 조정합니다. 모듈 허브의 검색 버튼은 분류 오른쪽에 고정하고, 검색을 열면 분류 대신 검색창을 표시합니다.

배포 버전 확인은 자동으로 실행하지만 새로고침은 하지 않습니다. 새 버전이 있으면 설정 위에 업데이트 아이콘을 표시하고, 클릭 시 저장을 마친 뒤 새 버전으로 이동합니다. 모바일에서는 하단 설정 위쪽에 같은 버튼을 표시합니다.
