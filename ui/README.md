# 공통 UI

`icons.js`: 24px 그리드, 1.75px 선, 둥근 끝과 모서리를 사용하는 앱 공통 SVG 아이콘팩입니다. 메인 문서와 React 제작 화면에서 같은 자산을 사용합니다.

`controls.css`: 버튼·입력·선택 컨트롤을 높이 40px, 모서리 10px, 테두리 1px로 통일합니다. 내용 카드와 일정 항목은 별도의 콘텐츠 요소입니다. 작업 버튼은 아이콘을 우선 표시하고 접근성 이름과 툴팁을 유지합니다.

`layout.css`: 검색 가능한 다중 프로젝트 목록과 플로팅 사이드바를 구성합니다. 좁은 화면에서는 사이드바가 오버레이로 열립니다.

운영자료는 별도 앱 메뉴 없이 프로젝트의 제작 화면 안에서 표시합니다. 기존 문서 편집 DOM은 슬롯으로 넣어 데이터와 편집 기능을 그대로 유지합니다.
